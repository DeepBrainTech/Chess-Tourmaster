====================================================
Chess Tourmaster - 快速启动指南
====================================================

选择你的启动方式：

方式 A: 使用 Docker（推荐生产环境）
方式 B: 本地开发环境

====================================================
方式 A: Docker 开发环境（推荐，支持热重载）⭐
====================================================

1️⃣ 启动开发环境：

   Windows:
   .\scripts\dev-docker.ps1

   Linux/Mac:
   chmod +x scripts/dev-docker.sh
   ./scripts/dev-docker.sh

2️⃣ 访问应用：
   应用: http://localhost:3000
   数据库管理: http://localhost:5555

3️⃣ 开始开发：
   - 修改代码自动生效
   - 无需重启容器
   - 实时查看效果

📖 详细说明见: DEV_DOCKER_GUIDE.txt

====================================================
方式 B: Docker 生产环境
====================================================

1️⃣ 前置要求：
   - 安装 Docker Desktop
   - 安装 Docker Compose

2️⃣ 配置环境变量：

   复制环境变量文件：
   copy .env.example .env

   编辑 .env 文件，设置：
   - JWT_SECRET=你的主站JWT密钥
   - TOURMASTER_JWT_SECRET=你的tourmaster密钥

3️⃣ 启动服务：

   docker-compose up -d

   这会自动：
   ✅ 启动 PostgreSQL 数据库
   ✅ 构建并启动 Next.js 应用
   ✅ 创建数据库表
   ✅ 启动 Nginx 反向代理

4️⃣ 访问应用：

   浏览器打开: http://localhost:3000

5️⃣ 查看日志：

   docker-compose logs -f app

6️⃣ 停止服务：

   docker-compose down

📖 详细说明见: DOCKER_GUIDE.txt

====================================================
方式 B: 本地开发环境启动
====================================================

1️⃣ 前置要求：
   - Node.js 18+
   - PostgreSQL 14+
   - npm

2️⃣ 安装依赖：

   npm install

3️⃣ 配置数据库：

   # 创建数据库
   psql -U postgres
   CREATE DATABASE chess_tourmaster;
   \q

4️⃣ 配置环境变量：

   copy .env.example .env

   编辑 .env：
   DATABASE_URL="postgresql://postgres:password@localhost:5432/chess_tourmaster"
   JWT_SECRET="你的JWT密钥"
   TOURMASTER_JWT_SECRET="你的tourmaster密钥"

5️⃣ 初始化数据库：

   npx prisma generate
   npx prisma db push

6️⃣ 启动开发服务器：

   npm run dev

7️⃣ 访问应用：

   浏览器打开: http://localhost:3000

📖 详细说明见: SETUP_CN.txt

====================================================
常见问题快速解决
====================================================

Q: 端口 3000 被占用？
A: 修改 docker-compose.yml 中的端口映射
   ports:
     - "3001:3000"  # 改为 3001

Q: 数据库连接失败？
A: 检查 DATABASE_URL 是否正确
   确保 PostgreSQL 服务已启动

Q: JWT 验证失败？
A: 确保 JWT_SECRET 与主站完全一致

Q: Docker 构建失败？
A: 清理缓存后重试
   docker system prune -a
   docker-compose build --no-cache

====================================================
有用的命令
====================================================

# Docker 相关
docker-compose ps              # 查看服务状态
docker-compose logs -f app     # 查看应用日志
docker-compose restart app     # 重启应用
docker-compose down -v         # 停止并删除数据卷

# 数据库相关
npx prisma studio              # 打开数据库可视化界面
npx prisma db push             # 推送数据库变更
docker-compose exec app npx prisma studio  # Docker 中使用

# 开发相关
npm run dev                    # 启动开发服务器
npm run build                  # 构建生产版本
npm start                      # 启动生产服务器
